You need to create a shortcut in Windows "Send To..." menu

1. Run `Win + R` and execute `shell:sendto`
2. In opened filder create new shortcut with name `Upload on Sharya`
3. Edit this new shortcut
4. Target: `"FOLDER_WITH_NODE_EXE\node.exe" src\main.js`
5. Start in: `SHARYA_REPO\uploader-script-nodejs`
6. Run: `normal window`
7. Run `yarn` in terminal in folder `SHARYA_REPO\uploader-script-nodejs`
